Description
In this guided lab, you will refactor an existing ASP.NET Core 10 application to follow Clean Architecture principles. You will restructure the application into layered boundaries, separate concerns, and reorganize dependencies to improve maintainability and testability.

T01 Analyze an existing ASP.NET Core 10 application structure to identify areas that violate Clean Architecture principles.
T02 Refactor application components into domain, application, infrastructure, and presentation layers.
T03 Apply dependency inversion to decouple application logic from infrastructure implementations.
T04 Verify the refactored architecture by running the application and confirming correct behavior.
